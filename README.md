# Data Job Postings Analysis Dashboard

## Project Overview

This project analyzes data job postings to understand job market trends,
demand for different data-related roles, required skills, locations, and
salary information.

The dashboard was created using Microsoft Power BI to transform raw job
posting data into meaningful and interactive insights.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Key Analysis

- Job postings by job title
- Job postings by location
- Salary analysis
- Most in-demand data roles
- Required skills
- Job posting trends
- Company and job market analysis

## Dashboard Features

- Interactive slicers and filters
- KPI cards
- Job role analysis
- Location-wise job analysis
- Salary analysis
- Skills demand analysis
- Interactive charts and visualizations

## Key Insights

- Identified the most in-demand data-related job roles.
- Analyzed locations with higher numbers of job opportunities.
- Compared salary trends across different roles.
- Identified commonly required skills in data-related jobs.
- Analyzed overall job market trends.
